# Capstone starter world: DRONE (quadrotor)

Квадрокоптер літає горизонтальним колом, водночас змінюючи висоту. Вас цікавить
**оцінка його повного 3D-положення** `(x, y, z, yaw)`. Єдиний файл, який Ви
редагуєте -- `controllers/capstone_drone/student_estimator.py`.

## Контракт

```python
StudentEstimator.estimate(sensors) -> (x, y, z, yaw)
```

`sensors` приходить щокроку:

- `dt` -- крок часу (с);
- `gyro_z` -- швидкість повороту навколо z (рад/с), гладка, зі зсувом;
- `speed` -- ГОРИЗОНТАЛЬНА швидкість (м/с);
- `baro` -- висота (м): гладка, часта, малошумна (барометр/альтиметр);
- `gps` -- абсолютні `(x, y, z)` із шумом, або `None` між оновленнями (~1 Гц).

За замовчуванням `estimate` повертає останній GPS-фікс -- baseline. Ваша задача --
побити його фільтром (KF/EKF/UKF).

## Родзинка цього світу: третій вимір і барометр

Головна відмінність від наземного світу -- **висота**. GPS по z значно шумніший,
ніж по x/y (як на реальних приймачах), а **барометр** дає гладку й часту висоту.
Правильно злити baro (згладжування z) із рідкісним GPS z -- і Ви отримаєте висоту,
кращу за будь-який із сенсорів окремо; саме тут -- основний виграш ATE. Для x/y --
той самий fusion gyro+speed із GPS, що й у наземному світі.

## Запуск

1. Відкрийте `worlds/capstone_drone.wbt` у Webots -> Play. Дрон полетить колом зі
   зміною висоти; наприкінці в консоль виведеться `3D ATE`.
2. Правте `student_estimator.py`, перезапускайте.
3. `python evaluate.py` -- будує `results/trajectory.png` (зліва x-y трек, справа
   висота z у часі) і друкує Ваш 3D ATE поряд із baseline.
